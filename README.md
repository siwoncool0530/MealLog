# MealLog

2026 모바일소프트웨어 학기 말 프로젝트 - 식단 관리 앱 만들기

## 현재 기능

- csv 형태로 저장된 음식 리스트를 앱에서 LazyColumn을 활용한 리스트 형태로 보여주기
- 데이터 출처: 식품의약품안전처 식품영양성분 데이터베이스 (🔗 https://various.foodsafetykorea.go.kr/nutrient/general/down/historyList.do)

## 사용한 프롬프트

``
MainActivity에서 assets/food_data.csv를 불러와서 LazyColumn을 활용한 리스트 형태로 출력할 수 있었으면 좋겠어.
``

``
데이터 출처인 "식품의약품안전처 식품영양성분 데이터베이스"를 앱에 보이도록 하고, 클릭하면 https://various.foodsafetykorea.go.kr/nutrient/general/down/historyList.do 링크로 접속할 수 있게 해줘.
``
